## 4. 黄山（并非）之旅！

**核心：2026.4.4–4.5 清明黄山行踩坑实录，先吐槽后升华。**

- **踩坑清单**：高铁很开心（第一次一起旅行 + 随时分享）；下高铁打不到车（310 块才到酒店）；酒店与宣传不符还在半山腰、房间 400 块但床潮浴室臭、没有床头灯；晚饭被宰（两荤一素 + 饮料米饭 199 块）；半夜找房间找了近 1 小时。
- **亮点**：晚上打牌看电视聊天 + 要到某人的 4 秒长视频和语音；黄山没票转去**九龙瀑**（40 元门票，人少景好，体验拉满）；西溪南滤镜破碎（普通皖南乡村，水又绿又臭）；当天傍晚改签回合肥（"我要回家"）。
- **教训**：旅游一定要做好攻略；订酒店别全信算法；热门景点提前买票；交通不便就去最有名的地方；优先选交通便利的；学会砍价。
- **启示**：旅游更重要的是和谁一起的过程；**福祸相依**（没上黄山躲开大堵车，九龙瀑刚刚好）。

## 6. 十万个为什么？（6 问，QA 卡片，持续扩充）

1. **为什么饮水机热水比直饮水便宜**：直饮水贵在净化成本（RO 滤芯耗材）、制冷比加热更耗能（先烧开再强制冷却）、以及"拧开就喝"的便利溢价；开水成本只需几分钱电费。
2. **为什么女性多内八、男性多外八**：女性骨盆宽浅 → 股骨自然内旋（+臀肌力量弱 + 审美强化）；男性肩宽、骨盆窄深 → 大腿偏外旋（+运动习惯）。只是倾向，非绝对。
3. **为什么冰杯比瓶装水贵**：制冰是缓慢高耗能过程；全程 -18℃ 冷链仓储运输（同冰淇淋逻辑）；PP 杯 + 封口膜成本高于 PET 瓶；税率更高（饮料 13% vs 水 9%）；卖的是"情绪价值 + DIY 便利"。
4. **为什么自行车能前骑不能后骑**：后轮花鼓内有"飞轮"单向传动装置——向前蹬棘爪卡合传递动力，向后蹬打滑空转；单向设计是为了滑行（停脚休息），双向锁死会伤膝盖、打脚（死飞就是例子）。
5. **为什么 1 元康师傅水大城市边缘化、县城常见**：大城市利润薄渠道不推、1 元=低端形象固化、2 元巨头夹击；小县城价格硬道理、康师傅靠方便面渠道渗透到乡镇末梢、本土杂牌衬托。城乡是不同市场生存法则。
6. **为什么专业厨师男性远多于女性**：体力硬门槛 + "家庭烹饪"与"职业厨师"的社会性别认知；"男性俱乐部"职场文化 + 玻璃天花板（女性多被分到冷盘甜品岗）；超长工时与家庭角色冲突；数据：顶级餐厅女性主厨可能低至 6%，美国女性主厨年薪少 1.6–1.9 万美元；年轻一代与教育渠道正在改变。
